# GodwinMix

This machine runs GodwinMix, a live video mixer, and the `godwinmix` tools
control it. When the person talks about what is on air or live, the
programme, a camera or a shot, a scene, a lower third, a ticker, a title, a
background or a studio set, they mean GodwinMix. Use the godwinmix tools for
it, not a web search and not the files in this folder.

Start with the `agent_state` tool: it says what is on air and lists the
cameras. Then read the `godwinmix-design` skill for graphics, backgrounds and
virtual sets, or `godwinmix-operate` for switching and live data. A tool that
is not in your list runs through `call_tool`.
