The mixer is not answering

This app is the control surface of a GodwinMix mixer, and it could not reach the mixer just now. If the mixer is running, whatever it is sending keeps going. Only this screen has lost it.

  • Is the mixer running? Check the machine it runs on, or the desktop app there.
  • Is this device on the same network? A phone that dropped off the Wi-Fi onto mobile data cannot see the mixer. A VPN on either end can hide it too.
  • Is the address still right? The app opens the address it was installed from. If the mixer's machine now has a different address on the network, open the new one in the browser and install the app again from there.
